📘 연결 방법 도움말
  1. ESP32는 2.4GHz 와이파이만 접속돼요. 학교 5G 와이파이에는 못 붙어요. 휴대폰 핫스팟을 2.4GHz로 켜고 ESP32를 연결하세요. (아이폰: 개인용 핫스팟 → 호환성 최대화 켜기 / 안드로이드: 모바일 핫스팟 → 대역 2.4GHz)
  2. ESP32와 이 웹앱은 Firebase를 통해 만나요. 그래서 이 웹앱은 학교 5G 와이파이, LTE, 집 어디서든 원격으로 제어돼요.
  3. 오른쪽 위 ⚙️ 에 Firebase Realtime Database 주소를 넣으세요. 아두이노 코드의 FIREBASE_URL과 같아야 해요.
  4. 정류장 이름으로 검색하면 ESP32가 공공데이터에서 찾아 결과를 보여줘요. 원하는 정류장의 선택을 누르세요.

⚙️ 연결 설정

Firebase 콘솔 → Realtime Database 상단에 보이는 주소를 붙여넣으세요.
예) https://my-busstop-default-rtdb.asia-southeast1.firebasedatabase.app
